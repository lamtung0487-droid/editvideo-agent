# Examples

| Folder / script | What it builds |
|---|---|
| [`public_domain/`](public_domain/README.md) | Archive films from public-domain sources the script fetches itself: `dossier_tonkin.py` (*Vịnh Bắc Bộ 1964*, a `dossier` montage) |

The other scripts in this folder are earlier reference builds (explainers, effects, recipes). Some of them expect
sources on disk: read each script's docstring before running it. The demo films and their credits are in
[docs/demo](../docs/demo/README.md).
