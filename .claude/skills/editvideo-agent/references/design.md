## Typography, color and graphic art direction

Read [design library](../../../../docs/DESIGN_LIBRARY.md) for16 font families/23 actual faces,24 role palettes,16 style kits,10 type roles,12 motion directions,10 components,12 SVG patterns and24 original icons. Start `design_catalog(kind,query,offset,limit)`; Vietnamese/English literal search, actual glyph/weight/italic/license/SHA evidence, paginated <=50. `read_design_preview(kind,id)` returns actual pixels: bundled-font/swatch sheets and observed engine frames. Those are reference specimens, not scores or guarantees of a finished video.

Choose one visual language across the film. First establish hierarchy, spacing and meaningful footage, then select purposeful motion. Usually use one body/caption family and a deliberate heading family; mono can serve code/data and a serif can serve quotations when their context needs it. No font-per-cut randomness. Use `layout_text(font_id,text,size,width,weight,italic)` before composing to probe NFC glyph coverage, actual FreeType advances/bounds and proposed line breaks; Chromium wrapping/tracking may differ. Keep Vietnamese marks clear; do not rewrite narration merely to fit a template. Verify selected normal/italic/weight exists; never advertise unbundled faces.

`derive_palette(seed,harmony,tone)` offers5 HSL harmony modes and dark/light role tokens with opaque sRGB contrast. Check real frames and busy footage, use solid surface for text when needed; don't use hue alone to encode facts. Color roles are background/surface/text/muted/accent/secondary/on_accent. UI contrast guidance is a readability reference, not a video accessibility stamp or automatic color grade.

`apply_design(project_id,base_revision,request)` accepts style_id, optional palette_id/heading_font_id/body_font_id and explicit layer_roles {id:role}. Type tokens cover display/headline/title/body/caption/label/source/data/quote/code; short-side1080 scale, weight/italic/leading/tracking and actual variable variation_axes (wdth/opsz where bundled) configurable via set_design. Axes/ranges validated; wght uses weight. Pass same axes to layout_text for matching measurement. Layer typography_role opts into type tokens; font_id overrides family. color_role/background_role opt into palette. Explicit untagged layer styling stays authored. This updates design atomically while retaining timebase/voice/custom source, and doesn't stack effects or grade footage automatically.

`compose_graphic` compiles10 real components after design selection. Read GraphicRequest schema. Meaningful text/detail, labels for steps/comparison, real value/unit/source for statistic; visible source for source_card/statistic. Same id refines its namespace atomically, dropping removed detail/source. Snapshot supplied inspect_frames, adjust line breaks/bounds/size and hold based on content. Text long enough to overflow is not solved by naming a style. Pattern/icon are original procedural SVG layers with bounded parameters/seed; keep background texture subtle and icons meaningful. Seven new effects word_reveal/line_reveal/character_reveal/text_gradient/underline_draw/radial_glow/edge_feather join69 total. Unit reveal holds final layout, frame-addressed; not spoken word timestamps. line_reveal follows authored newlines.

New Remotion/Hyperframes exports carry verified local font files/licenses/manifest and design.cjs/design.js loader, waiting for FontFace. No CDN/OS-font dependency for selected library fonts. Data refresh embeds selected fonts without silently rewriting custom source. Existing customized entry must deliberately merge design runtime/entry integration through current runtime resource plus read/write hash/backup. Hyperframes design.js precedes hyper-runtime.js. FFmpeg simple renderer doesn't run DOM/font-loader/graphic layers. `scripts/design_atlas.py` builds real dual-engine samples; global timeline supports1000 layers, avoid many simultaneously active decorations. No studio or required approval step.
