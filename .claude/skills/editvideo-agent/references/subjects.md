## Subject masks, inpainting and generated footage

Read [subject and generation guide](../../../../docs/SUBJECTS_AND_GENERATION.md) and `editvideo://schemas` before these operations. `track_subject` runs SAM2 video memory with normalized source-frame boxes/positive/negative points, full per-frame masks and tracked boxes. Windows <=15s/450 frames; each object needs a frame-0 prompt, later-frame prompts correct occlusion. Poll `get_media_task`, inspect `read_subject` inline overlay/mask pixels, then `refine_subject` with complete replacement prompts for selected object/frame. Sessions remain immutable. Nonempty mask/visible is not identity confidence; labels are yours, not automatic semantic verification.

`edit_subject` uses those masks to remove/blur/replace background/extract transparent foreground/grade/spotlight/outline/reframe. Reframe follows subject center into any aspect ratio with smoothing. Mask edits preserve source resolution by default; mask-resolution output is an explicit fast option, and LaMa limits only fill inference size. For temporally consistent removal use backend propainter: bidirectional flow/image propagation and temporal sparse transformer. temporal_max_size512, window60, overlap12, neighbors6 bound processing; scene_cuts supplement automatic hard-cut detection and prohibit cross-shot propagation. ProPainter is optional/pinned and uses the upstream non-commercial S-Lab license. LaMa remains framewise; optional flow blending is not a temporal neural model. Inspect hallucinated background, overlapping subjects, edge halos and flicker. Empty masks hold last crop center. Foreground gives alpha WebM and RGBA sequence; separate audio can be placed through timeline clips. Fresh Remotion scaffold decodes alpha via `transparent`; existing custom source may need this prop added explicitly.

`generate_footage` supports installed local_ltx (cached CUDA LTX2B distilled, prompt or reference first-frame image) and configured ComfyUI/Runway. Discover dimensions/limits in media_capabilities: local example width512,height320,fps24,frame_count73,duration3; multiples32, frames8*n+1<=161. Local uses CPU offload, VAE tiling and a pinned T5 encoder with FP8 linear storage and per-module BF16 computation, reducing host RAM; optional original encoder installation is documented. It has no negative_prompt/reference_mask/workflow and never downloads during inference. Render precise text/diagrams separately. External adapters remain optional. No key/provider/model is assumed; never describe an unconfigured provider as usable. For ComfyUI, discover actual `generation_nodes`, register a valid API graph with parameter bindings and video saver, then submit. The task snapshots the graph; missing bindings retain authored values and are reported. Request one purposeful shot with subject/action, camera, lighting, composition and space for editable labels. Keep precise text/diagrams in React/HTML. Generation is reconstruction, not source evidence. Runway uses only `EDITVIDEO_RUNWAY_API_KEY`; external generation may incur provider cost.

Tasks survive MCP closure; cancel only the selected task. Poll sensible intervals, observe actual result, then `attach_media_result` with latest project revision: it adds an asset while preserving locked narration/timeline/plan. Patch shot/layer using returned revision/asset id, snapshot/render, inspect again. Provider HTTP tests do not establish live generative model quality. Actual SAM2/LaMa/ProPainter and alpha composition have verification artifacts; local generation live status requires a completed model task. import_media with preserve_plan=true/current base_revision returns {asset,revision,plan_preserved} and adds local media without recreating narration.
