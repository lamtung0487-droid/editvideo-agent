## Professional editorial workflow: TikTok to long YouTube

Use [professional playbook](../../../../docs/PROFESSIONAL_VIDEO_PLAYBOOK.md) and `professional_toolkit(platform,query)` to choose story, layout, caption, evidence and audio techniques. Define audience, promise, learning objective, visual evidence and payoff first. Short form needs a clear situation/idea and useful demonstration; long form needs coherent questions/chapters/examples and resolution. TikTok ad recommendations are starting points, not organic-content laws. No universal cut frequency or invented retention score. Typography/reading time, motivated cuts, source meaning, dialogue clarity, continuity and one focal motion per beat matter more than effect count.

`compose_edit` applies16 executable recipes atomically with current revision: hook_card/lower_third/chapter_card/evidence_card/pull_quote/keyword_callout/PiP/comparison_labels/focus_spotlight/tracked_callout/word_captions/chapter_progress/J-cut/L-cut/sound_bridge/audio_finish. Read RecipeRequest schema. Use unique id per beat; same id refines its existing layers. Optional dry_run is not a required approval step. Inspect suggested frames and actual playback. Platform safe_region values are editable conservative heuristics; check current UI and subject/text collisions, override as needed. Evidence card needs verified source_text; labels alone do not establish truth.

Timed captions support2000 pages within one layer, retaining stable phrase layout and active-word box/color/underline. Match real TTS word timing to display cue or supply word_timings from corrected ASR mapped to narration seconds with timing_source. Never synthesize word timing by dividing text length. ASR/30fps quantization is estimated, not forced alignment. Callout SVG keeps label still while target_keyframes move its anchor; normalize to canvas after source contain/crop/playback mapping. No semantic identity guarantee. New widgets/effects require current source runtime: resource editvideo://runtime/{engine}/{filename} supplies individual templates. Read project code/hash, merge/write deliberately with backup; preserve custom entry. New exports have the runtime; data patches do not silently rewrite old code.

`read_audio_events` supplies acoustic onset candidates/quiet intervals and measured loudness, plus audio excerpt. Flux is not BPM/meaning and pause is not automatically dead air; listen with transcript/context before editing. `design_sound` creates5 local procedural sound kinds, no learned audio model/API. Import preserving plan, place/fade/duck sparingly. AudioMix controls target LUFS/true peak/LRA and music ducking; per AudioClip.ducking controls threshold/ratio/attack/release. Defaults preserve existing two-pass -16LUFS behavior; this is an editorial default, not a universal platform requirement. J/L audio recipes need real pre-roll/continuation handles and separate selected audio; do not double dialogue already in locked narration.

Twelve new effects include diagonal/diamond/soft reveal, slide_spring, focus_zoom, defocus_pulse, fade_pulse, light_sweep, paper_grain, text_outline, marker_reveal and display-space exposure. Discover amount/targets/cautions and actual atlas pixels. They are graphic/display operations, not neural depth rack-focus, scene-linear/HDR grading or real camera reconstruction. For techniques beyond this scope, custom code remains available; do not advertise unsupported nonlinear speed ramps, moving source-handle transitions, audio separation or a fullHDR browser compositor as integrated. Native color media/LUT/relative depth/authored3D are now documented in COLOR_DEPTH_3D.md.
