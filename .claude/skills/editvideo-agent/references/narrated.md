## Narrated video

1. Define the learning objective, audience and one clear thread. Write a Vietnamese script with a useful opening, explanation/example and concluding idea. Avoid stock filler that does not explain the spoken point.
2. `editvideo_create_project`: title, script, profile, renderer `remotion` or `hyperframes`. `spoken_text` can expand numerals/acronyms for speech while script/captions preserve readable spelling.
3. Import useful local media with `editvideo_import_media`. Index footage with `editvideo_index_video`, then inspect selected temporal windows using `editvideo_inspect_window`; crop details when needed. Tags help discovery but do not establish what footage depicts. Images/video are illustration unless their source genuinely supports the spoken claim.
4. For an existing narration, import audio and set `narration_id` using `editvideo_configure_project`. Otherwise `plan` generates Vietnamese Edge TTS. `editvideo_submit_job(kind="plan")` returns immediately; read job status at sensible intervals until completed/failed.
5. Read the project. Timeline durations come from actual voice samples. `estimated_from_script` means captions are estimated for uploaded narration. Use `editvideo_transcribe` on the locked voice, correct uncertain terms against audio, and apply returned cues/SRT. Word timestamps are ASR estimates, not forced alignment. First model use needs explicit `allow_download=true`; subsequent cached inference is local.
6. Read `editvideo://schemas`. Set aesthetic direction with `set_design`; use `editvideo_aesthetic_packet` and optional references to reason about hierarchy, typography, framing, palette, pacing and narration alignment. Search `editvideo_effect_catalog` by English purpose/id/family; inspect real atlas previews before unfamiliar techniques. Patch with current revision: split/move cuts, update shot effects/keyframes/transition/rate, upsert layers/audio, replace cues. Use `editvideo_read_narration` for measured TTS words; preserve meaning units rather than mechanically splitting every nine words. Batches are atomic.
7. Export the selected engine with `editvideo_export_code` once. Runtime v2 updates timeline/config/media in render snapshots while preserving entry/runtime custom code; no reexport is needed for ordinary patches. Existing source requires explicit `overwrite=true`; rebuilding replaces scaffold customizations. Legacy v1 source needs a deliberate one-time v2 migration preserving custom code.
8. Read and edit source with `editvideo_read_code` / `editvideo_write_code`, passing the SHA256 from the read. Normal coding-agent file tools are also usable. Snapshot exact code frames, inspect the returned pixels, and adjust diagram layout, text size, cue placement and animation where needed.
9. Render preview or final, then observe the actual MP4 and listen to audio. Fix specific observed problems. Deliver the MP4 and editable source ZIP paths from `editvideo_get_job`. No score, critic panel or approval phase is required.
