## Aesthetic direction

The calling multimodal AI reasons about aesthetics from actual evidence; the runtime does not claim to score beauty or replace visual judgment. Read [director guide](../../../../docs/AESTHETIC_DIRECTION.md) when framing/refining content. Use intent → evidence → interpretation/uncertainty → concrete edit → inspected result. Keep one focal motion per beat and sufficient reading time; effect count is not quality. Never assert what unseen intervals depict. Unsupported semantic retrieval, fullHDR browser composition, semantic re-identification must not be described as integrated. ProPainter supplies temporal neural inpainting; do not claim it restores unseen factual background perfectly. State provider configuration and live-test status honestly.
