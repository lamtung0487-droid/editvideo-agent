# Geodata

`ne_50m_admin_0_countries.min.geojson.gz`: Natural Earth 1:50m admin-0 countries, version 5, with only the name fields
the code reads (ADMIN, NAME, NAME_LONG, NAME_VI, SOVEREIGNT, ISO_A3, ADM0_A3). Natural Earth is in the public domain
(https://www.naturalearthdata.com/about/terms-of-use/). "Made with Natural Earth."

Maps use it when no other country geodata is registered in the resource library (`resources.geo_outline`).
